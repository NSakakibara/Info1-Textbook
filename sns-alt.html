参考：SNSの代替テキストの付け方

学んだことは、今日からSNSで実践できます。各SNSでの具体的な設定方法を見ていきましょう。

Instagram

インスタは写真がメインなので、代替テキストが特に重要です。

投稿するとき

  1. いつも通りに写真を選び、フィルター編集などを進めます。
  2. キャプション（投稿文）を書く最後の画面で、一番下にある「詳細設定」をタップします。
  3. 下の方にスクロールすると「アクセシビリティ」という項目があり、そこに「代替テキストを記述」という欄があります。
  4. そこをタップして、写真の説明を入力すれば完了です。

すでに投稿した写真に入れるとき

  1. 自分の投稿の右上にある「…」（三点リーダー）をタップします。
  2. 「編集」を選びます。
  3. 写真の左下あたりに「代替テキストを編集」（または人の形のアイコン）が表示されるので、それをタップします。
  4. 説明を入力して保存します。

X（旧Twitter）

Xは情報のスピードが速いですが、画像にもしっかり代替テキストを付けられます。

投稿するとき

  1. 写真や画像を添付すると、画像がサムネイル（小さいサイズ）で表示されます。
  2. その画像の上にある「説明を追加」または「ALT」というボタン（ペンのマークの場合もあります）をタップします。
  3. 説明文を入力するボックスが出てくるので、1000文字以内で説明を入力します。
  4. 「保存」を押して、投稿すれば完了です。

★便利なヒント

Xの設定で「アクセシビリティ」→「画像の説明リマインダー」をオンにしておくと、代替テキストなしで画像を投稿しようとしたときに「忘れていませんか？」と教えてくれるので便利です。

✕注意

残念ながら、Xは（今のところ）一度投稿したツイートの画像や代替テキストを後から編集することはできません。投稿するときに入れ忘れないように注意しましょう。

Facebook

FacebookにはAI（人工知能）による自動の代替テキスト機能がありますが、自分で直した方がずっと正確です。

投稿するとき

  1. 写真を追加して投稿作成画面を開きます。
  2. 追加した写真の左上にある「写真を編集」（ペンのマーク）をタップします。
  3. 上部に「代替テキスト」（「ALT」と書かれたアイコン）というボタンがあるので、それをタップします。
  4. Facebookが自動生成した説明（例：「屋外、空、雲」など）がすでに入っていることが多いです。
  5. その自動テキストを消して、自分で考えた正確な説明文を上書きします。
  6. 「保存」して投稿すれば完了です。

すでに投稿した写真に入れるとき

  1. 編集したい写真をクリックして大きく表示します。
  2. 右上に表示される「…」（三点リーダー）または「オプション」をクリックします。
  3. 「代替テキストを変更」を選びます。
  4. AIが作ったテキストを、自分で考えた説明文に上書きして「保存」します。

TikTok

TikTokでは、写真投稿には代替テキストを、動画には字幕を付けられます。

写真投稿の場合

  1. 写真を選び、「次へ」をタップします。
  2. 投稿画面の「その他のオプション」から「代替テキストを追加」を選びます。
  3. 各写真について、内容や目的が伝わる説明を300文字以内で入力します。
  4. 「完了」をタップして投稿します。

投稿後も「…」→「投稿を編集」→「代替テキストを追加」から追加・修正できます。

動画投稿の場合

自動字幕を利用し、投稿前に内容を確認しましょう。特に、人名や地名、数字、専門用語は誤変換されやすいため、修正が必要です。また、映像だけで伝えている重要な情報は、ナレーションや投稿文でも補うと、より多くの人に内容が伝わります。

iご注意

機能名や操作方法は、アプリの更新によって変わる場合があります。（2026年8月確認）
