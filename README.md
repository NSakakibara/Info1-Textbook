高等学校 情報Ⅰ 補助教材「情報アクセシビリティをはじめよう」の Web 版です。

ライセンス：CC BY-NC-SA 4.0

公開URL: https://nsakakibara.github.io/Info1-Textbook/

---

## この教材の方針

- **ビルド不要** — すべて素の HTML と CSS です。`git push` するだけで公開されます。
- **外部依存は Google Fonts のみ** — 画像も含めてすべてファイル内で完結しているので、
  学校のネットワークが不調でも、フォントが標準フォントに置き換わるだけで動きます。
- **教材自身がお手本** — 見出しの階層、表の `scope` 属性、リンクの下線、コントラスト比、
  キーボード操作。教材で教えている内容を、この教材自身が守っています。

### デザインについて

紙の教材の組版にならっています。

- 本文は **BIZ UDPゴシック**（ユニバーサルデザインフォント）、見出しは **明朝**。
  Windows・Mac には同等のフォントが入っているので、ネットにつながらなくても崩れません。
- 色は **墨・藍・朱** の3色に絞っています。文字色はすべて背景に対して
  コントラスト比 4.5:1 以上（本文は 8:1 以上）です。
- 強調は蛍光ペン風の背景ではなく **圏点＋太字**。囲みは色だけでなく
  枠線の位置と ○ ✕ ★ の記号でも区別できます。印刷しても意味が失われません。

## 公開のしかた

1. このリポジトリにファイルを置いて `git push` します。
2. GitHub の **Settings → Pages** を開きます。
3. **Source** を `Deploy from a branch`、ブランチを `main`、フォルダを `/ (root)` にします。
4. 1〜2分待つと公開されます。

## PDFの作り方

1. `print.html` をブラウザで開きます。
2. `Ctrl`＋`P`（Mac は `⌘`＋`P`）で印刷ダイアログを開きます。
3. 送信先を「**PDFに保存**」にします。
4. 用紙は **A4縦**、余白は「標準」で構いません。

「背景のグラフィック」はオフのままで大丈夫です。囲みは枠線、強調は圏点＋太字、
飾り罫も罫線で描いてあるので、背景を印刷しなくても情報は失われません。

## 編集するときの注意

GitHub Pages でよくつまずく点です。

- **ファイル名は必ず半角小文字＋ハイフン。** Windows のローカルでは大文字小文字を区別しませんが、
  GitHub Pages は区別します。`Style.css` と `style.css` は別のファイルとして扱われ、
  「ローカルでは動いたのに Web では表示されない」の原因になります。
- **パスは相対で書く。** 公開先がサブディレクトリ（`/Info1-Textbook/`）なので、
  `/assets/style.css` と書くと 404 になります。`assets/style.css` と書いてください。
- **日本語のファイル名は使わない。** URL が長くエンコードされ、QRコードが読み取りにくくなります。
- **更新が反映されないときはスーパーリロード。** `Ctrl`＋`F5` で確認してください。
  CSS を大きく変えたときは、各ページの `style.css` を `style.css?v=2` のようにすると確実です。

## `_build/` について（使わなくても構いません）

`_build/` には、この HTML 群を生成した Python スクリプトが入っています。

- `content.py` … 各ページの本文データ
- `build.py` … HTML を書き出すスクリプト（`python build.py ..` で親フォルダに出力）
- `style.css` … 共通スタイルシートの原本（ビルド時に `assets/` へコピーされます）

**公開されている HTML は完成品なので、ビルドは不要です。** 少しの修正なら
HTML を直接編集するのが早道です。全ページのデザインをまとめて変えたい、
章を大きく入れ替えたい、といったときだけお使いください。
（`_` で始まるフォルダは GitHub Pages では公開されません。不要なら削除して構いません。）

## 内容を書き換えるには

各 `.html` ファイルを直接編集してください。共通部分（上部の帯、下部のフッター、
前後のページ送り）は各ファイルに直接書かれているので、全ページに関わる変更をするときは
エディタの「フォルダ内を一括置換」をお使いください。

トピックを追加する場合は、既存のページをコピーして中身を差し替え、
`index.html` の目次と、前後のページの「ページ送り」にリンクを足してください。
